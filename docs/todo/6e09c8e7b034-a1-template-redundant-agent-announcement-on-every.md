Note on the script block: keep type="text/bashsharp". Per the HTML standard a script whose type is not a JavaScript MIME type, module or importmap is a data block: never fetched, parsed or executed, kept in the DOM (the JSON-LD and client-template precedent), inert under a strict CSP. Do not change it to text/javascript with comments: a strict CSP blocks and logs inline JS, the engine parses it, and '*/' or '</script>' inside the recipe would break it. The recipe must not contain the literal </script> and should be plain ASCII.
