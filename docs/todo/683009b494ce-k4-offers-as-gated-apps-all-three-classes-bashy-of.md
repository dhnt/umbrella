- Door routes (pkg/broker, new file offers.go, wired in the ServeHTTP switch like /files):

  - POST /offers/NAME with JSON {args: {...}} -> runs the offered typed tool and returns its JSON result plus usage: class model -> the M1 llm call path with the model fixed; class agent -> the M1 agent path (bashy delegate --json --read-only) with --max-tokens = token_cap (delegate already enforces or refuses the cap: that IS the K4 token cap; record it in the Delivery); class tool -> an in-process slash run of NAME carrying the caller principal in cligw.WithPrincipal so K1/K3 checks apply; files-NAME -> the F1 call (and its /files/NAME byte route).
