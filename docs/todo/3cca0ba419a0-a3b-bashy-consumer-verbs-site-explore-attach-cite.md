- WIRE CONTRACT (matches A1):
  * `/agents.txt` (`text/plain; charset=utf-8`): `key: value` lines up to the first blank line (`site`, `title`, `module`, `revision`, `index`, `agents_md`, `markdown`, `json`, `skill`, `skills_index`, `mcp`, `mcp_card`, `source`, `edit`, `shape`, `cite`, `bashy`; ignore `#` comments and unknown keys), followed after `\n\n` verbatim by the `## For agents {#agents}` Markdown prose block.
  * `Bashy-Shaped` header: comma-separated `k=v` pairs (`module="<module>", revision="<rev>", agents="/agents.txt", skill="/skill.md", mcp="/mcp", source="<source>", shape="/?shape=open"`); accept both `agents` and `agents.txt` and strip optional surrounding quotes.
  * `Link` header: RFC 8288 links (`alternate` for `text/markdown` and `application/json`, `describedby` `/llms.txt`, `edit`, `via`, `service-doc` `/AGENTS.md`, `service-desc` `/.well-known/mcp/server-card.json`, `canonical`, `author`, `help`).
  * Twins: Markdown front matter `agent: {instructions, agents_txt, index, skills, skill, mcp, source, edit, cite}` + `## For agents {#agents}` first in body; JSON top-level `agents: {instructions, agents_txt, index, skills, skill, mcp, source, edit, shape, cite, recipe}` + `path`, `title`, `summary`, `revision`, `nav`, `sections[{id, heading, html, markdown, sha256}]`; HTML `<script id="agent-recipe" type="text/bashsharp">`.
  * `/.well-known/agent-skills/index.json` (schema `0.2.0`): `{"version":"0.2.0","skills":[{"name":"<owner>-site","type":"skill-md","description":"...","url":"/skill.md","sha256":"<hex>"}]}`.
- VERB BEHAVIOR:
  * `bashy skills add <url>` / `bashy skill add <url>`: accepts `http://` or `https://` URL (either a site origin/page, `/.well-known/agent-skills/index.json`, or a direct `SKILL.md`/`skill.md` URL), verifies `sha256` when `index.json` declares one, stages into a temp folder, and runs the existing verified-admission gate (`admit` + `installSkill`).
  * `bashy site explore|attach|cite|shape|recipe <url>` (all with `--json` and `--dry-run`): `explore` probes `/agents.txt` first with fallback chain (`Bashy-Shaped`, `Link`, Markdown twin `agent:` + `## For agents`, `/AGENTS.md`, `/llms.txt`) and fails gracefully with `'not an agent-ready site'` when none exist; `attach` admits the site skill via `skills add` and records the site in `kb`; `cite <url>#<id>` returns `{url, section_id, revision, section_sha256, quote}`; `shape <url>` discovers `source` repo, registers as `--type shaped` (respecting `--dry-run`), and prints `wish`/`verify`/`preview`/`approve`/`undo`; `recipe <url>` prints the `text/bashsharp` recipe by default and runs ONLY on `--run` in the guarded Bash# sandbox (`dag.CapExecHandler`) with effects capped to `read,net` and URLs restricted to `<origin>` and URLs literally named in the recipe (refusing any recipe that exceeds cap or targets foreign origins).
