# Bash command invocation counts — findings of record

Measured 2026-11-10 on the dev box. Question asked: list every bash command
and sort by the number of invocations, from private memory and the bash
OpenTelemetry records. This is a read-only report; no product change follows
from it.

## How to read the names

- **Versioned claude basenames.** `2.1.284`, `2.1.283` and `2.1.282` are the
  basenames of the versioned Claude Code binary. Merged with `claude` they
  total 288,931, which makes claude the most-invoked command.
- **bashy verbs count as commands.** `model`, `sprint`, `weave`, `fetch`,
  `inbox`, `todo`, `mb`, `kb`, `commands` and the like are in-process bashy
  verbs recorded like any external command. `model` is almost entirely the
  `model quota capture` poller; `fetch` is the provider balance poller.
- **Polling floor.** `sleep` (272,943) and much of `git` (`git status
  --short`) come from watch loops, not from interactive work.
- **Tail noise.** Single-count entries such as `@timed`, `=======`, `-c`,
  `--help` are mis-parsed one-offs, kept for completeness.

## Reproduce

Execlog, all history:

```bash
/usr/bin/find ~/.bashy/exec -type f -name '*.jsonl' -path '*/2026-*' -exec /bin/cat {} + \
  | jq -r 'select(.stage=="episode") | .cmd' | sort | uniq -c | sort -rn
```

OTel spool, current day:

```bash
jq -r 'select(._msg|startswith("exec ")) | .cmd_name' ~/.agents/otel/spool/spans.jsonl \
  | sort | uniq -c | sort -rn
```

Note: the in-process `xargs` does not chunk argument lists; `find -exec … +`
does, which is why the first command uses it.
